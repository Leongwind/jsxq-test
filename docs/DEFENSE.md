# 15 分钟答辩提纲

## 0:00–2:00 需求与边界

目标用户是把经历转化为求职行动的高校学生。首版解决一次「简历文本 → 岗位要求 → 证据与缺口」决策，不做账号、文件上传或聊天平台。说明材料来自题目脱敏 PDF，预置 JD 有真实招聘来源。

## 2:00–6:00 产品演示

1. 打开工作台，载入 Java 脱敏样例，选择后端岗位，查看 JD 和来源。
2. 开始分析；指出加载和输入保留行为。
3. 展示匹配分数、权重分子分母、命中项的简历证据与岗位证据。
4. 展示「简历未体现」的缺口和可行动建议，以及结构化简历与问题。
5. 切换自定义 JD，例如「必备 Java、Spring Boot；加分 Redis、Docker」，说明分析针对当前岗位。
6. 展示移动布局；若当前是测试模式，主动说明标识及真实模型验证记录，不把测试桩演示称为真实 AI。

## 6:00–10:00 请求链与算法

- 浏览器网络面板只有同源 `/api/jobs` 和 `/api/analyses`。
- 展开诊断，复制 requestId；用相同 ID 对照 BFF、Java、Python 日志，日志不含完整简历。
- 解释 BFF 与岗位领域服务的不同职责，展示 Java 强类型 DTO 与 Python Pydantic 校验。
- LLM 只提取事实，程序检查证据和别名后计算权重。解释 Java 不能被 JavaScript 误匹配、版本要求和通用要求的区别、中文技能去重。
- 一次模型调用、明确超时，无静默重试或测试结果回退。空 JD/错误字段会在调用模型前拒绝。
- 用户选择 DeepSeek，接口保持 OpenAI-compatible；说明与题目提及 GPT/Claude 品牌的区别。

## 10:00–13:00 测试、CI 与回滚

- 展示真实测试结果和 GitHub PR checks；用测试桩实现无密钥、可重复 CI。
- 区分组件测试、全容器协议测试与真实 LLM 调用的证据。
- 展示四服务健康状态、只有 Web 暴露的端口以及 SHA 镜像标签。
- 使用 `scripts/deploy.sh <上一已验证SHA> --local` 展示回滚；不演示未经验证的远端服务器部署。

## 13:00–15:00 取舍与下一步

- 三小时内优先完整五层闭环、可验证结果和工程交付。
- 岗位用只读版本化 JSON，无数据库；用户输入不持久化。
- 分数衡量技能证据覆盖，不是招聘决定；缺少证据不等于没有能力。
- 模型仍有提取遗漏、优先级理解与表达差异；严格证据约束减少虚构，也可能漏掉隐含能力。
- 复杂 OR 要求、跨技能等价推断、学历/年限评分、线上多用户鉴权限流属于后续范围。
- 以 DELIVERY.md 的实际结果说明所有已验证项和缺口，不夸大 CI、模型质量或生产可用性。
